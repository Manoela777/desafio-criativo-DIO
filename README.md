# Desafio Criativo — Extraindo Insights do Feedback de Clientes Bancários

Projeto desenvolvido durante o **Bootcamp Bradesco - GenAI, Dados & Cyber**, da DIO.

## 📌 Sobre o projeto

O desafio consiste na construção de um prompt utilizando Inteligência Artificial Generativa para analisar feedbacks de clientes sobre a utilização de um aplicativo bancário.

A proposta é transformar comentários dos clientes em informações estruturadas que possam auxiliar na identificação de problemas, elogios e oportunidades de melhoria.

## 🎯 Objetivo

Criar um prompt capaz de orientar uma IA na análise de feedbacks, considerando:

- Assunto do feedback;
- Tom da mensagem;
- Prioridade;
- Efeito sobre o cliente;
- Principais padrões, problemas, elogios e oportunidades de melhoria.
